## Consumed sizing and clipping witnesses

For this plan only, capture_consumed_sizing opts into private intent/order fields.
`desired_targets(..., witness=...)` records the actual already-computed D NAV,
cash/holdings, eligible microprices, rational weights and returned target at that
call site, with lot/unit, decision ID and exact formation quote identity/time.
EXIT is typed NOT_APPLICABLE without invented target-sizing snapshots.
`maximum_buy(..., witness=...)` records the actual cash, execution microprice,
spend cap, fee-rule inputs and returned affordable bound at that call site.
Native orders link those to leg/day/side/symbol and actual pre-order holdings;
zero delta is explicitly ZERO_DELTA_NO_ORDER, not a fabricated venue order.
Legacy primitive callers get the same return value and no witness by default.
No extra target/affordability calculation changes execution. The saved verifier
checks these consumed values against saved fills/quotes/weights and exact floor,
fee/settlement/affordable-bound equations; it does not reconstruct missing fields
or claim absent old A7 operands were saved.
