contract, plus its original pre-outcome protocol, under
research_candidates/quant_a_fomc_calendar. These exact bytes are statically packaged
for adapter qualification. Engineering does not select or tune its economic rule;
final Quant strategy review follows actual backtest. Old calendar/CPI configs,

The existing Service/CLI research-config accepts polar.fomc-calendar-seed/1.
It follows no source refs. Required fields are schema, namespace, question_id
FOMC-CALENDAR-ONLY-REFERENCE-01, candidate_id, experiment_id, consumer_task,
source_admission_ref, and immutable input_ref, index_ref, protocol_ref,

polar.fomc-calendar-config/1; use existing research-preflight/research-run and
research-recompute with its returned fomc-calendar-experiment ID. A seed/factory
or metadata preflight is not a runnable retained operation.

Source roles schema polar.fomc-source-roles/1 binds input_ref, phase_bounds and
phases VALIDATION/FINAL. Each phase retains the complete available earlier prefix
and complete declared NAV grid for BIL and VTI. Rows explicitly contain symbol,
date, close_ns, available_ns, source_id and role, with the same input-id/symbol/date
metadata locator recipe. available_ns can remain null. This is a caller metadata
locator, not an invented provider permanent ID or proof of historical availability.
The official index bytes are pinned exactly; every source row remains in geometry
including unresolved, timing and boundary exclusions. Runtime geometry is computed
from schedule/statement metadata and pinned New York TZif bytes and must equal
geometry_ref; RETAINED also requires those actual installed runtime timezone bytes.

Clock schema polar.fomc-quote-clock/1 binds namespace, basis, roles_sha256,
assumption_ref and source_fit_ref. UNKNOWN requires null availability throughout
and prevents FIRST_START. No next-midnight clock is supplied by this branch.
INVENTED is restricted to invented positive-provenance fixtures. A future explicit
synthetic clock needs the Quant-authored polar.fomc-explicit-quote-clock-assumption/1
with question_id/roles_sha256/basis/historical_K UNKNOWN and a matching accepted
source-fit record bound to its exact hash. This is a modeled assumption, never a
source or historical known-by fact. Current actual clock/coverage remains unresolved.

method_ref and qualification_ref use polar.fomc-method/1 and
polar.fomc-qualification/1, with namespace, question_id, policy_sha256,

intent; existing supplied legacy grant paths are unchanged and strict.
