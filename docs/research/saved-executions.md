# Saved execution readback

GET `/v1/research/results/{result_id}/executions?series_id=ID&limit=100&offset=0` reads the requested saved account. Omit series_id to use the unique STRATEGY series. No producer, source loader, evaluator, model, or native engine is invoked; no artifact is written.

The result content ID binds the semantic-manifest hash. Only the required saved simulation member is read and hash/byte checked: old raw CI simulation.json; reference ridge/scheduled phases.json; PPO final.json. The exact phase, all account IDs, grid, NAV, positions, cash and cumulative costs must match the immutable public record. Training/model/dev inputs are not read. Invalid or missing tape is an error/unavailable, never a fabricated zero-order result.

`polar.research-executions/1` returns result/content/series/phase identity, semantic/member digests, original basis, quote_basis, quantity_unit, status, total and pagination. `status=OK,total=0` is known empty; UNAVAILABLE has total=null. Each event contains order_id, symbol, side, timestamp_ns as a decimal STRING, ISO nanosecond timestamp, intended/routed/filled quantities as integer strings. FILLED includes saved price_micro (USD per declared unit times1e6), fee_cents and settled_notional_cents. NOT_ROUTED retains the original intent and reason, has filled quantity zero, and null fill price/fee/notional. No fallback to close or inference from positions. Ordering is timestamp then stable native order ID.

A saved native symbol is not by itself a history instrument identity. A UI must resolve source/instrument compatibility explicitly. `raw_ohlc_overlay_compatible=false` requires an exact basis join; synthetic vendor-adjusted reference-unit fill prices must use a separate explicitly labeled compatible reference-price axis/layer, never raw-share candle USD or portfolio NAV Index100. Prices and nanoseconds retain exact string representation. Current API does not claim an observed real-world execution or calibrated trading capacity.
