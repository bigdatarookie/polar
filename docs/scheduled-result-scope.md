# Scheduled result scope wording

Future no-ML-fit scheduled publications supply the existing cohort limitation
from their declared profile symbol count. A single selected VTI policy is one
source alias even when its input manifest contains a larger parent cohort; a
GLD/IEF/VTI profile is three. No broad-universe, economic continuity or independent
bet count is inferred. Selection/survivor conditioning remains disclosed.

The scheduled producer supplies NO_ML_FIT_EVALUATION_PHASES with its exact existing
partition description, rather than an inherited TRAIN_DEVELOPMENT_TEST heading.
This does not remove calibration, estimator or optimization accounting or alter
phase, metrics, criteria, clocks or financial status. Generic non-scheduled
projection defaults and explicit cohort overrides remain unchanged. Both new
codes continue through the existing Data & Design and Limitations renderer.

Only future generated metadata changes. Original saved result bytes, IDs,
semantic artifacts and trial history remain immutable. Inherited incorrect cohort
wording/stale headings in an old record are disclosed through its existing exact
independent assessment scope_description, without rewriting its record or values.
No old-result producer/recompute, financial rerun, serving update or UI wave is
needed or authorized by this source correction.
