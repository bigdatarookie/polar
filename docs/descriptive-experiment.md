It adds no scheduler, model, optimization, trading strategy, statistical test, Sharpe, funded NAV or HYP/Gym verdict. It uses only admitted private-owner history; the four current assets do not become an original historical universe.

Invoke explicitly through the existing Service/CLI:

```sh
polar history-experiment /private/path/config.json
```

Each validated invocation creates a new UUID4 directory under history-experiment-attempts, with immutable started.json BEFORE reading/computing the registered input. Receipt.json adds actual completion/status/elapsed/process-CPU provenance after execution; started.json retains the actual environment and complete operative source-file hash projection, including for failures. Actual constructed/completed time is not historical feature availability.
