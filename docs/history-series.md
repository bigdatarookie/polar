# Retrospective history series

GET `/v1/history/datasets/{dataset_id}/revisions/{revision}/series` adds backend numeric values to the accepted pinned history API. It uses the existing private-owner access boundary and persisted pagination key. It performs no admission, job, database, import or provider operation.

Required query fields: instrument_id, start and end (inclusive start, exclusive end). Dates, identifiers, cursor and span bounds match bars. Optional limit1..1000, warmup_sessions0..2500, cursor, sma_period/ema_period/bb_period/rsi_period (strict integer2..500), bb_deviation (finite exact Decimal0<k<=10, at most40characters and exponent>=-18), benchmark_instrument_id (default hist-us-0004/VTI), reference_family (default RAW_PRICE_RELATIVE or PROVIDER_ADJUSTED_CLOSE_INDEX), basis (RAW_CLOSE only). Omitted periods disable their series; bb_period without deviation uses2; deviation without bb_period is422. UI defaults20/20/20/2/14 must be sent explicitly when enabled.

Schema polar.history-series/1 retains the bars envelope: pinned dataset/revision/receipt/manifest/bases, request_identity, window, rows/row_count, coverage, fitness, warmup, next_cursor and window_complete. Added fields: calculation_version polar.history-calculation/1, numeric_version decimal50-v1, definition_sha256, effective parameters, series_metadata, reference_metadata and bounded reset summary. No full prefix or reset tape is transferred. Each response contains at most1000total points including warmup and1MiB encoded JSON; byte-limited pages return fewer points and a signed continuation. The cursor binds all numeric/parameter/calendar/reference/input identities and the requested transport limits/window. Invalid/mismatched cursors422; corrupt artifacts409; unknown revision/instrument404; empty window200/EMPTY_WINDOW.

Each point contains session_date, row_role, segment_origin and fixed values/statuses maps keyed sma,ema,bb_middle,bb_upper,bb_lower,rsi,asset_reference,benchmark_reference. Values are canonical derived decimal strings or null; statuses are VALUE, UNAVAILABLE or DISABLED with stable reason. Per-point GAP/INVALID_PRICE/WARMUP/UNRESOLVED_GAPS remains distinct from observed zero. Expected missing reference dates produce series gap points, never padded OHLCV bars. Transport warmup counts these reference points when qualified; it is separately marked and paged. Coverage counts are clipped to the asset's admitted first/last dates; no unavailable prehistory or posthistory is invented.

All computations start at the full admitted revision/segment before window filtering. SMA/EMA/Bollinger/Wilder RSI use raw close and private Decimal50/HALF_EVEN with the frozen operation order and canonical tuple serialization. Missing/invalid closes reset state, recursive arithmetic failures remain unavailable until a real segment reset. No arbitrary2500point transport seed or viewport rebasing. Per-series metadata identifies the full-revision first valid date, final segment available history, origin, reset/error counts and computation start. These are not per-page sufficiency counts.

Reference normalization uses100*price/first-common-valid-price in the entire revision, independently for the asset and benchmark under one selected family/currency/reference calendar. One missing leg makes both paired values null; a later valid pair returns to the same anchor. Raw references are price-only and not action-correct wealth; provider adjusted-close references are a provider-methodology proxy, not independently reconstructed total return or funded NAV. No dividends/actions are added again. Empty comparable intersections and NO_OVERLAP stay explicit.

The separate adopted dates-only common-US-reference sidecar is configured with POLAR_HISTORY_CALENDAR_DIR (default artifact-root/history-calendar), containing calendar.json and binding.json. This endpoint makes retrospective chart arithmetic available. It does not implement an experiment, original-HYP fitness, financial performance, Sharpe, funded portfolio or predictive feature readiness. Legacy bars, fixtures, retained report URLs and schemas are unchanged.
