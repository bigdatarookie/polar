## Shared command and private operation

Author and independent technical checks use the accepted shared `scripts/ci.sh --source CHECKOUT --test tests/test_ci_research.py --test tests/test_research_results.py`; native Gym and actual Node controls remain applicable. All fixtures are invented. Local licensed inputs never enter public Actions or its logs/artifacts.

The existing `polar` CLI/Service expose `research-config SEED.json`, `research-preflight CONFIG.json`, `research-run CONFIG.json`, and `research-recompute SEMANTIC_ID`. File-only operations use Settings.load_artifacts and never need a DB secret. Set POLAR_ARTIFACT_ROOT to the existing trusted persistent artifact mount and preserve it through attempts; POLAR_STORAGE_BYTES retains validated64GiB policy. The executor observes the actual official image and sets POLAR_RUNTIME_IMAGE_ID; Python starts with a fresh task-private `-X pycache_prefix=...` and PYTHONDONTWRITEBYTECODE=1. This avoids ambient owner bytecode without deleting or excluding it from a source-inventory claim.

A config seed has namespace INVENTED or RETAINED, profile_id, protocol_path, input_path, timezone_path, code_revision, runtime_image_id, candidate_id, experiment_id and optional execution_authority_path. Config assembly hashes references and loaded source deterministically; no financial calculation or grant is performed. Preflight verifies exact source/protocol/input/timezone/native/runtime/root identity and returns counts/pins plus operation_binding_sha256, never prices or results. Known retained input/source fingerprints cannot be relabeled INVENTED. Retained calls require the exact frozen input and method. A/B private inputs remain11754099/262b0b7a; no recapture/reselection.

The SRE-owned trusted local operation grant schema is polar.ci-research-operation/1, with binding_sha256 equal to preflight, input_classification RETAINED, action ORIGINAL, expected_prior_attempts (exact sorted immutable family attempt IDs), method_ref, candidate_ref and qualification_ref (SHA-bound local references). Method refs are53d50330 for A and277d4e1a for B; candidate reservation ID/profile must match. Qualification is actual polar.ci-result/1 PASS on this code_revision and selected tests or test_ci_research.py, not author prose or another PR's control. CI timing floats are parsed as inert metadata tokens, never finance. A correction after a failed original also requires a separately bound correction_ref; a successful original prevents another native original. B allows no second original after any admitted or unknown native boundary. A positively recorded failure before simulate was invoked is NOT_REACHED, not a scientific event; all technical attempts remain preserved. No automatic refunds or reset are performed.

artifact_root_identity in generated config is the canonical path/device/inode observed in the executing container's own namespace, verified again before use and covered by the operation hash. It is not equated to host inode or a claim of host mount attestation. SRE's actual same-container image/mount/source receipt binds the host trusted persistent root separately. Changing/recreating the local root invalidates the config; starting a fresh root is not recovery. Families are keyed by namespace/profile/input, independent of config/code/run ID, so changing a technical config does not silently reset the scientific family.

## Publication, failures and stored recomputation

Before child execution an immutable conservative INTENT and original config/grant are fsynced in ci-research-attempts. Child code is rechecked before native import; per-account start/first-market-event/completion facts are retained. Bound parent process timeout/reap protects one finite call. Failure records preserve charged/unknown boundary and private bounded UTF8 traceback/partial ledgers; these private diagnostics are never projected by HTTP or uploaded as public research output. No blind retry or fake NOT_STARTED from missing evidence.

Successful outputs publish immutable simulation/evaluation/bindings and an acyclic hash manifest under ci-research-experiments, then the public research-result/1 projection under the existing artifact root. Start/finish identity is separate from content identity. PUBLIC API remains read-only and shows unreviewed financial status until the actual independent content-bound sidecar. No financial PASS comes from publication.

research-recompute verifies stored manifest/member hashes and reproduces evaluation from stored simulation. It never reloads raw source, calls a strategy/native engine, creates orders or writes the store. It is stored recomputation, not a second simulation or a repaired trade tape. Both successful and failed original evidence remain. B's one-original policy is not replaced with A's qualified-correction allowance.

Public ledger units: ledger.cash and ledger.exposure are exact decimal USD amounts (exposure is the sum of marked asset values), as are cumulative_flat_fees and cumulative_bps_fees. They must not be formatted as percentages. Only the named mean_close_equity_fraction/mean_close_exposure and invested-close fractions are dimensionless ratios. B's displayed return/CAGR explicitly say modeled price-ledger after costs; they are not total-return labels.
