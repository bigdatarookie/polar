# Fixed-R0 source observability

`polar hyp003-observability CONFIG --output-dir NEW_ABSOLUTE_DIR` projects existing availability metadata. It performs no acquisition, index rebuild, price arithmetic or financial computation. This capability does not authorize a retained invocation; DE owns the separately assigned operation after qualification.

Use closed `polar.hyp003-observability-config/1` with `mode` INVENTED or RETAINED, exact `{path,sha256}` refs `availability_ref`, `population_ref`, `grid_ref`, `ledger_ref`, and a nonempty `evidence_refs` array. RETAINED admits only the frozen b16db/R0/grid/all-default ledger and scientific input binding. The normative wire definition is `src/polar/hyp003_observability_schema.json`.

The projection checks the parent content identity and hashes each selected metadata member while interpreting it once. It verifies the full population, original record objects/ordinals, exact dates and ledger defaults. It reuses prior raw graph validation, and does not claim a new audit of raw bodies, observation prices or candidate evidence assertions. Malformed or unbalanced inputs fail closed; partial output has no terminal manifest. Existing output directories are never overwritten.

Five semantic outputs contain record/date totals, civil-quarter × stored-decile × WARMUP/STUDY × source-state × applicability/default tables (including zero strata), overlapping profile/observation/coverage diagnostics, and unresolved fitness/predicates/bounds. Decile is static source order, not liquidity. Unknown or absent decile remains UNKNOWN. All positions remain UNKNOWN_APPLICABILITY under this packet's evidence adoption, independently flagged ASSUMED_EXPECTED_DEFAULT. Request intervals are not economic listing intervals. Three-field equivalents are scope bookkeeping, not field qualification. Profile/error facts and inherited unlinked/outside-grid counts never enlarge dense totals.

The terminal manifest hashes outputs, input/evidence pins, source and schema. Its revision excludes physical paths/time/attempt; `physical-receipt.json` holds those references separately. Source state/source quality/applicability/fitness are distinct; unknown applicability does not imply true missingness or suitability. Economic denominator and guarded schedules/windows stay unidentified/unbound; old99% failure remains historical. This fixed-R0 projection does not discharge all13026-T lineage/exclusion obligations or admit an original-HYP run.

Limits reuse the accepted dimensions (3514 records/1008 dates), 256KiB line, 16MiB dense member,128MiB index/ledger/output member. They protect bounded local parsing/allocation, not a coverage target. Integrity failure routes PE correction and affected independent QA; explicit UNKNOWN is a valid negative descriptive result. Scientific/user/provider limits are unchanged.
