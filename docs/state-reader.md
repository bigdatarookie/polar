# Read-only Polar state projection v1

Run `python3.13 scripts/polar_state.py --qitem qitem-YYYYMMDDhhmmss-hex --root /explicit/artifact/root --attempt UUID`. Omit qitem or artifact selectors when not applicable. `--experiment gym-<sha256>` selects one known immutable experiment; it never discovers attempts. Use an existing absolute non-symlink artifact root. No service/DB/provider, polling, writes, locks, run/recovery command, or new truth store is used. The wrapper disables bytecode writes before importing Polar.

The one native operation is `rig queue show ID --full --json` (10second deadline,256KiBstdout limit, stderr discarded, own process group terminated/reaped on failure). Existing native owner/state/blocker projections are selected; queue body/summary/answers and arbitrary text are never printed. Qitem ownership is not an exclusive filesystem-writer lease or worker heartbeat.

`polar.state/1` stdout has fixed fact fields: queue_state, owner, queue_custody, source_custody, worker_liveness, checkpoint, terminal_result, semantic_result, consumer_ack and next_step. Each carries KNOWN/UNKNOWN, value, reason, freshness and evidence with source/reference/SHA/read observation and producer event time. Unknown values are null. Stale recorded values may appear only as explicitly historical `last_recorded`, never current liveness. Observation time is measured per source read within the returned query-start/end window; event clocks do not become observed worker clocks. Native current query is a fresh observation even when the row's last transition is old.

Supported artifact adapter: accepted polar.gym-attempt-start/1, polar.gym-attempt-finish/1, polar.gym-semantic-manifest/1. It reuses the existing safe descriptor-based read and Gym canonical identity/file set conventions. Start/finish records are read from exact selected UUID paths. Success is joined to its exact experiment ID and all four bounded semantic member hashes; raw data/model/metric/config bodies are not displayed or decoded by this metadata reader. An explicitly selected conflicting experiment, mismatched native owner/state, impossible attempt clocks, invalid schema/hash or missing claimed result yields UNKNOWN with a stable reason. A filename or a Reconnecting line alone proves nothing.

Gym has no supported independent worker heartbeat, mutable progress checkpoint or consumer acknowledgment schema. Those facts remain UNKNOWN, including after a successful terminal result; a qitem done/delivery acknowledgment does not prove artifact consumption. A fresh start receipt alone is not evidence of a running worker. Unsupported loader/HYP007/other formats remain UNKNOWN; no guessed adapter or provider invocation. This first reader is not a universal registry or financial validator.

Freshness: default max-age300seconds, explicit `--max-age-seconds`1..86400. Attempt producer timestamps older than the threshold or in the future make current terminal claims UNKNOWN; safe last_recorded metadata may be shown for context. Cryptographic immutable content verification is a fresh read observation, independent of a historic producer timestamp. Missing event time gives UNKNOWN freshness. Each read is a bounded snapshot, not a cross-system transaction; no claim of atomicity across native queue/files. No automatic incident/recovery inference follows stale or contradictory evidence. Next step is a fixed informational suggestion, not an executed action.

Limits: at most12explicit file reads, default1MiB/file and8MiBtotal; caller may lower or raise within4MiB/file and16MiBtotal. Large artifacts fail closed as UNKNOWN rather than widening limits or dumping them. Paths cannot escape root, traverse symlinks or read FIFO/device files; existing history_bundle.safe_root/read_file primitives enforce this. Output is allowlisted metadata, hashes, relative references and status codes, at most64KiB. Caller chooses the root; this is not an OS sandbox or authorization to inspect arbitrary private directories. No home/credential discovery or child run commands exist.

Exit0 means projection produced; UNKNOWN facts are normal and are not PASS/acceptance. Invalid CLI/selector/bounds gives a stable JSON error and exit2. Tests use only disposable invented records and mocked native reads; independent Code/System QA owns actual acceptance. No financial/Gym/provider readiness is implied by a prepared projection.
