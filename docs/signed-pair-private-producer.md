This is a closed source/invented research component built on the accepted signed core, exact native account, serial event driver and immutable store. It is not a Service admission interface, operation allocation, broker, public result or UI projection. The scientific choice is frozen merged contract v2 `8f4a1ae99499a9663aa6e741e4a9da17b76f84becb3459d028dfdb912fa6760c` plus the opening/settlement, current-mark, due-payment/time, economic-continuation, paired-checkpoint and comparator-scope owner clarifications. It supplies four controls and twelve predefined cases, without fitting/searching/tuning a strategy.

## Saved scalars and immutable graph

`polar.signed_pair_metrics.metrics(account)` and `evaluate(accounts)` consume saved operands. Use `verify_account`/`verify_study` with caller-owned exact binding first; scalar functions alone do not authenticate source/native evidence. Exact mean/sample variance and inequality operands precede D50 projections. Volatility projects exact252*variance before square root. Sharpe projects exact mean/variance separately; CAGR uses the TRADING252 logarithm/exponent recipe. Context precision/rounding/exponents/traps and raised flags are explicit. Nonpositive NAV/default makes ordinary full-path ratio statistics inapplicable, without dropping samples or hiding dollar deficit/drawdown. Drawdown retains latest equal peak and first maximum trough, including depth above1; recovery is first later return to that original peak. Daily ES is signed loss with descending loss/date tie and ceil(n/20), retaining negative ES. Worst20 uses overlapping20-return endpoints. Wealth, growth, DD and survival remain independently available; known failure wins over missing required reports/controls.

Private metrics include actual commissions split flat/bps, settled turnover including entry/EXIT, borrow/debit recognized/settled origins, distribution amounts, dollar and defined-domain exposure/drift, margin/checkpoint deficits/buffer minima, forced/locate/recall/default counts. Primary comparisons and required candidate survival use only the predefined baseline/eight required cases; destruction paths report separately. No independent financial/adoption verdict is issued by this producer.

`polar.signed_pair_saved.binding_for(data)`, `verify_account`, `verify_study`, `publish_account`, `verify_stored_account`, `publish_study` and `verify_stored_study` provide the private consumer. Whole graph membership is exactly4x12, not a favorable subset or five-curve split. Source-absent checking replays supplied actual callbacks through pure accepted account arithmetic, checks D/END/native/NAV/target/source-role/fee/activation joins and recomputes saved numerical outputs. It never invokes native, provider, Service, ranking/policy selection or writes. This is internal immutable consistency under a caller-bound accepted tuple, not cryptographic authentication of an arbitrary rehashed source/native history.

The existing store holds manifest/header plus ordered gzip record/NAV chunks. Compressed and uncompressed hashes/lengths/census/order are pinned; decompression is bounded before parsing and rejects trailing/multiple streams. Every unpacked chunk is at most one-quarter of the unchanged existing32MiB object limit. No rows/IDs/operands are dropped. Compression uses fixedmtime0; duplicate strings may share reader memory without changing bytes. Existing store quota is still enforced; useful partial immutable objects may survive a later publication error and are not a complete study. A half-long fullshape fits the former object path; the spread fullshape exceeded it and the512MiB verbatim test allowance, motivating lossless chunks rather than a cap increase or truncated tape.
